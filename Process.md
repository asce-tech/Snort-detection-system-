## Introduction
The purpose of this project is to learn about the operation of an intrusion detection system. Usage of Snort to create rules to detect and generate alerts whenever there is a matching packet. Viewing the traffic generated in Wireshark. 

## Pre-requisites
- Basic understanding of web servers, HTTP protocols, and Internet Protocol addresses.
- Familiarity with the Linux command line

## Lab Set-up and Tools
- Ubuntu virtual machine with Snort installed
- Your Host OS
- Snort
- Wireshark
- Putty

## Steps

Step 1: Set up the environment.
- Install Snort:
```bash
   sudo apt update
   sudo apt install snort
```
- Install Wireshark: for capturing and analyzing network traffic.
```bash
   sudo apt install wireshark
```
- Install Putty: to establish SSH connections with the Snort virtual machine.
```bash
sudo apt update
sudo apt install putty
```

Step 2: Capture Network Traffic using Wireshark. View and save the file, naming it `SnortTraffic.dat`

Step 3: Create Snort rules:
- On your virtual machine desktop, create a text file `SnortLab.conf`.
- Add the following rules : 
- To detect `FTP` attempts:
```bash
alert tcp any any -> any 20:21 (msg:"FTP connection attempted"; sid:1000001; rev:1;)
```
- To detect `SMTP` packets:
```bash
alert tcp any any -> any 25 (msg:"SMTP Connection attempted"; sid:1000002; rev:1;)
```
- Save the Configuration file

Step 4: Now, run the `SnortLab.conf` & `SnortTraffic.dat` using the terminal.
```bash
snort -c SnortLab.conf -r SnortTraffic.dat
```
- Observe the output for the number of packets processed and the protocol breakdown.

Step 5: View Snort  Alerts
- Check the Snort alert log by running
```bash
cat /var/log/snort/alert
```

Step 6: Modify Snort Rules and Re-run Snort
- Modify the rules in SnortLab.conf to detect specific IP connections
```bash
alert tcp 192.168.23.133 53537 -> 192.168.23.131 20:21 (msg:"FTP connection attempted"; sid:1000001; rev:1;)
alert tcp 192.168.23.133 48866 -> 192.168.23.131 25 (msg:"SMTP Connection attempted"; sid:1000002; rev:1;)
```
- Re-run Snort:
```bash
snort -c SnortLab.conf -r SnortTraffic.dat -N
```

Step 7: Generate Live Traffic and Run Snort
- Determine the virtual machine IP:
```bash
ifconfig
```
- Add Snort rule for remote login:
```bash
alert tcp any any -> [virtual machine IP] 22 (msg:"Remote Login"; sid:1000001; rev:1;)
```
- Use Putty to establish an SSH connection to the virtual machine.
- Run Snort again to monitor live traffic:
```bash
snort -c SnortLab.conf -i eth0
```
- Observe the alerts generated by Snort for SSH traffic.
